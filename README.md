# Vezore- Video learning Platform for new generation

The project is about a platform where you can upload a video get all kinds of notes, understand from the context of the video not just repetitive ai generated outputs. You can generate short notes, practice questions and all the history of you learning will also be saved 

## Tech Stack 
Frontend: React, CSS 
Backend: Nodejs
Database: MongoDb
Video Storage: Cloudinary
